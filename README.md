# 통합업무지시 솔루션

영업 · 고객 · 행정 · 인사 — 8개 지사 통합 업무지시/모니터링/평가보상 플랫폼 프로토타입 (서버 없는 프론트엔드 데모)

배포 주소: https://heebonpark.github.io/task-order-solution/

담당지사·역할(SP/SE/SG/지사장/영업팀장/고객팀장/지사내근/본부장/사업지원팀장/담당자)을 화면 상단에서 선택하면 그 역할 기준으로 화면이 바뀝니다.

## 공유용 링크

역할별로 바로 원하는 화면으로 진입할 수 있도록 링크를 나눠뒀습니다. (진입 후에도 상단에서 지사/역할을 자유롭게 바꿀 수 있습니다)

| 대상 | 링크 | 설명 |
|---|---|---|
| 업무지시 (중간관리부서·본부) | https://heebonpark.github.io/task-order-solution/?v=orders | 업무지시 등록/목록 화면으로 바로 진입 (기본 역할: 담당자) |
| 모니터링 (본부) | https://heebonpark.github.io/task-order-solution/?v=monitor | 전 지사 대시보드로 바로 진입 (기본 역할: 본부장) |
| 수행자 (SP·SE·SG 현장) | https://heebonpark.github.io/task-order-solution/?v=exec | 본인 업무 목록으로 바로 진입 (기본 역할: SP) |

수행자 링크는 역할/지사를 URL에 직접 지정할 수도 있습니다. 예: `?v=exec&r=SE&b=강릉` (강릉지사 SE로 진입)
