# 통합업무지시 솔루션

영업 · 고객 · 행정 · 인사 — 8개 지사 통합 업무지시/모니터링/평가보상 플랫폼 프로토타입 (서버 없는 프론트엔드 데모)

배포 주소: [heebonpark.github.io/task-order-solution](https://heebonpark.github.io/task-order-solution/)

담당지사·역할(SP/SE/SG/지사장/영업팀장/고객팀장/지사내근/본부장/사업지원팀장/담당자)을 화면 상단에서 선택하면 그 역할 기준으로 화면이 바뀝니다.

## 공유용 링크

역할별로 바로 원하는 화면으로 진입할 수 있도록 링크를 나눠뒀습니다. (진입 후에도 상단에서 지사/역할을 자유롭게 바꿀 수 있습니다)

| 대상 | 링크 | 설명 |
| --- | --- | --- |
| 업무지시 (중간관리부서·본부) | [`?v=orders`](https://heebonpark.github.io/task-order-solution/?v=orders) | 업무지시 등록/목록 화면으로 바로 진입 (기본 역할: 담당자) |
| 중간모니터링 (지사장·영업팀장·고객팀장·지사내근) | [`?v=branch`](https://heebonpark.github.io/task-order-solution/?v=branch) | 본인 지사로 스코프 제한된 대시보드로 바로 진입 (기본 역할: 지사장) |
| 본부 모니터링 | [`?v=monitor`](https://heebonpark.github.io/task-order-solution/?v=monitor) | 전 지사 대시보드로 바로 진입 (기본 역할: 본부장) |
| 수행자 (SP·SE·SG 현장) | [`?v=exec`](https://heebonpark.github.io/task-order-solution/?v=exec) | 본인 업무 목록으로 바로 진입 (기본 역할: SP) |

수행자 링크는 역할/지사를 URL에 직접 지정할 수도 있습니다. 예: `?v=exec&r=SE&b=강릉` (강릉지사 SE로 진입)

## 추가 기능

- **관리자 모드**: 화면 상단 "관리자" 비밀번호 입력 시 전 지사·전 권한(업무지시 수정/삭제, 전 지사 수행자 관리 포함)으로 전환됩니다. 비밀번호는 담당자에게 별도로 전달받으세요. ⚠️ 서버 없는 프론트엔드 데모라 이 잠금은 화면(페이지 소스)에서 우회 가능한 UI 편의 기능이며, 실제 접근 통제가 아닙니다.
- **수행자 관리**: 중간관리부서는 본인 지사, 관리자는 전 지사의 SP·SE·SG 인원을 등록/삭제할 수 있습니다.
- **수행 등록 강화**: 현장 수행자는 지시별로 조치결과(진행중/완료/기타), 특이사항, 사진촬영, 첨부파일을 등록할 수 있습니다.
- 지사 목록의 "원주"는 "원주(춘천)"으로 표기됩니다.
